# Security Policy

If a repository has its own `SECURITY.md`, that one applies. For the CLI, loader and modules, see the [security policy in stagepass-one/os](https://github.com/stagepass-one/os/blob/master/SECURITY.md), including supported versions.

## Reporting a vulnerability

Please report security issues privately. Do **not** open a public issue, discussion or pull request for an undisclosed vulnerability.

1. Preferred: use GitHub private vulnerability reporting on the affected repository. For `os`: [report a vulnerability](https://github.com/stagepass-one/os/security/advisories/new).
2. Alternative: email [hello@stagepass.one](mailto:hello@stagepass.one) with the subject `Security`.

Please include the affected package and version, steps to reproduce and the impact you expect. Do not send real credentials or customer data.

We aim to acknowledge reports within 7 days and will keep you updated until the issue is resolved. We are happy to credit you in the advisory unless you prefer to stay anonymous.
