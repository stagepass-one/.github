# .github

Organization profile and default community health files for [Stagepass](https://stagepass.one).

- `profile/README.md` is the public profile on [github.com/stagepass-one](https://github.com/stagepass-one).
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, issue forms and the pull request template apply to every repository in the organization that does not ship its own version.

Repository-specific files always win. For the Stagepass CLI, loader and modules, see [stagepass-one/os](https://github.com/stagepass-one/os).
